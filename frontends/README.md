# Minimal Agent GUI

本地 Web 界面使用 Python 标准库提供 HTTP 服务。先按[主 README](../README.md#快速开始)配置 API，再从项目根目录运行。

```bash
python3 -m frontends.server
```

打开 `http://127.0.0.1:8899/`。可用 `--port 8766` 指定端口，或用 `--config 路径` 指定 API 配置文件。

支持创建和切换会话、聊天、工具调用提示、plan 卡片和用户 todo 卡片。与 CLI 共用核心目录的 `data/`、`temp/` 和 API 配置，重启后可续接会话。各会话的模型任务在后台线程中执行，界面轮询快照，不阻塞切换会话。每个会话同时只允许一个 GUI 请求。

“停止”使用核心的协作取消：正在进行的 HTTP 请求会等到返回或超时后才能结束。界面展示持久化的阶段结果，暂不逐 token 输出。上下文压缩仅作用于模型请求副本，完整聊天记录保留供界面展示；旧版本已经裁剪掉的消息不会自动恢复。

服务仅监听本机，修改接口校验随机令牌。工具仍拥有当前用户的代码执行和文件访问权限，请仅在自己的电脑上使用，不要公开端口。同一个会话请避免同时在 CLI 和 GUI 中运行任务，因为核心目前没有跨进程会话锁。

聊天回复支持 Markdown（标题、列表、表格、代码块、链接等），使用本地 vendored marked 15.0.12（MIT）和 DOMPurify 3.4.17（Apache-2.0 或 MPL-2.0）渲染并清洗，不依赖运行时 CDN。原始 HTML 受标签白名单限制，不加载回复中的远程图片。

工具调用按连续调用分组，默认只显示名称与结果状态；展开后可查看参数及结果。未确认执行的占位结果不会标为成功。

每次任务默认最多进行 40 轮模型调用；可通过启动参数 `--max-steps 80` 调整。任务完成后会提前结束。
